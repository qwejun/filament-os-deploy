## 📦 第一章：智能耗材管理

### 1.1 闪电入库 —— 3 秒完成耗材登记

**🤖 AI 视觉识别入库（花果山黑科技）**

对着耗材标签拍张照，系统自动识别：
- ✅ 品牌 Logo（拓竹、eSun、Polymaker 等 50+ 品牌）
- ✅ 材质类型（PLA、PETG、ABS、TPU、ASA、PC 等）
- ✅ 颜色名称 + 色号（如"11100 象牙白"）
- ✅ 重量规格（1kg、500g、250g）

**批量入库模式**
```
📸 拍照 → 🤖 AI 识别 → ✏️ 批量确认 → ✅ 一键入库
  3 秒        2 秒          5 秒          1 秒
```
一次拍摄最多支持 10 卷耗材同时识别，入库效率提升 10 倍！

**智能 ID 生成系统**
- 格式：`YYMMDD-XXX`（如 240401-001）
- 支持 ID 预留，多人同时入库不冲突
- 扫码枪直接扫描 ID 查询耗材详情

```bash
# 克隆仓库
```

#### 2. 配置环境变量

```bash
# 复制配置示例
```

```bash
docker-compose up -d
```

#### 4. 访问系统

打开浏览器访问：http://localhost:2233

- 用户名：admin（或你设置的 INIT_ADMIN_USERNAME）

### 8.4 数据目录

首次运行会自动创建：
- `./data/` - 数据库
- `./uploads/` - 上传文件
- `./backups/` - 自动备份
- `./bambu-config/` - 打印机配置
- `./bambu-streams/` - 视频流缓存
- `./timelapse/` - 延时摄影
- `./logs/` - 日志文件

### 8.5 常用命令

```bash

docker-compose down

docker-compose restart

# 更新到最新版本
docker-compose down

docker-compose up -d
```

### 8.6 注意事项

1. **首次启动较慢**：Bambu Printer Service 需要约 60 秒初始化
2. **修改默认密码**：首次登录后请修改 admin 密码
3. **视频流延迟**：RTSP 转 HLS 有约 3-5 秒延迟，属正常现象
4. **端口冲突**：如果 2233 被占用，修改 docker-compose.yml 中的端口映射

### 8.7 故障排查

#### 服务无法启动
```bash
docker-compose logs
```

#### 数据库问题
```bash
docker exec -it filament-osv2 sh
ls -la /app/data/
```

#### 打印机无法连接
```bash
# 检查打印机服务状态
docker-compose ps
curl http://localhost:5000/printers
```

### 8.8 安全建议

1. 修改默认密码
2. 配置 HTTPS（建议使用反向代理）
3. 定期备份 data 和 uploads 目录
4. 不要暴露 5000 端口到公网
