# Filament OS

3D打印耗材管理系统 - 完整的耗材库存、打印机监控和AI智能助手解决方案

## 快速开始

### 1. 安装 Docker 和 Docker Compose

请先安装 [Docker Desktop](https://www.docker.com/products/docker-desktop)

### 2. 克隆或下载部署文件

```bash
git clone https://github.com/qwejun/filament-os.git
cd filament-os/filament-os-deploy
```

或者直接下载 docker-compose.yml 文件

### 3. 配置环境变量

```bash
# 复制配置示例
cp .env.example .env

# 编辑 .env 文件，设置管理员密码
# INIT_ADMIN_USERNAME=admin
# INIT_ADMIN_PASSWORD=YourSecurePassword123
```

### 4. 启动服务

```bash
docker-compose up -d
```

### 5. 访问系统

打开浏览器访问：http://localhost:2233

默认管理员账号：
- 用户名：`admin`（或你设置的）
- 密码：`ChangeMe_123456`（或你设置的）

## 功能特性

### 📦 耗材库存管理

#### 基础功能
- **耗材入库** - 支持OCR拍照识别批量入库
- **耗材出库** - 打印完成自动扣减库存
- **库存编辑** - 修改耗材信息（重量、状态、位置等）
- **库存查询** - 多维度筛选（品牌、材质、颜色、状态）
- **全局搜索** - 支持ID、颜色、品牌等关键词搜索

#### 耗材属性
- **品牌管理** - 支持拓竹、eSun、Polymaker等品牌
- **材质类型** - PLA、PETG、ABS、TPU、ASA等
- **颜色系统** - 支持色号查询（如11100象牙白）
- **状态追踪** - 已开封/未开封、有盘/无盘
- **重量记录** - 实时记录剩余重量
- **位置管理** - 自定义存放位置

#### 数据可视化
- **库存概览** - 总卷数、已开封、有盘/无盘统计
- **品牌分布** - 饼图展示各品牌占比
- **材质统计** - 柱状图展示材质分布
- **颜色矩阵** - 材质-颜色交叉分析
- **状态图表** - 开封状态、盘芯状态可视化

### 🤖 AI 智能助手

#### 智能问答
- **库存查询** - "有多少卷PLA？"、"蓝色耗材还剩多少？"
- **ID查询** - "ID40号是什么耗材？"、"最后入库的ID是多少？"
- **颜色查询** - "11100是什么颜色？"、"有哪些蓝色耗材？"
- **价值估算** - "库存总价值多少？"、"PLA耗材值多少钱？"
- **打印报价** - "打印100g模型多少钱？"
- **智能推荐** - "推荐一个蓝色PLA"

#### AI 配置支持
- **智谱AI** (GLM-4-Flash)
- **DeepSeek** (DeepSeek-Chat)
- **硅基流动** (Qwen系列)
- **OpenRouter** (Gemini等)
- **自定义API** - 支持任意OpenAI兼容接口

#### 视觉识别
- **切片截图识别** - 上传Bambu Studio截图自动识别参数
- **OCR识别** - 自动提取重量、时间等打印参数
- **智能报价** - 根据识别结果自动计算成本

### 🖨️ 打印机监控

- **多打印机支持** - 同时监控多台打印机

## 配置说明

### 端口映射

默认使用 `2233` 端口，如需修改请编辑 `docker-compose.yml`：

```yaml
ports:
  - "8080:2233"  # 改为 8080
```

### 数据持久化

- `./data` - 数据库文件
- `./backups` - 备份文件
- `./uploads` - 上传文件

这些目录会被持久化到宿主机。

### 环境变量

| 变量 | 默认值 | 说明 |
|-----|-------|------|
| INIT_ADMIN_USERNAME | admin | 管理员用户名 |
| INIT_ADMIN_PASSWORD | ChangeMe_123456 | 管理员密码 |
| DATABASE_URL | file:/app/data/database.sqlite | 数据库路径 |
